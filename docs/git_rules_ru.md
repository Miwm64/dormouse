# Правила Git

## Имена веток
Должно быть `master`, `develop` или `<type>/...` (например, `feat/login`).

## Заголовки коммитов
Формат: `<type>(scope)!: description`
- **Тип**: `build | chore | ci | docs | feat | fix | perf | refactor | revert | style | test`
- **Scope**: необязательно
- **`!`**: необязательно (для breaking change)
- **Максимальная длина**: 72 символа

## Заголовки PR
Тот же формат, что и у заголовков коммитов.

## Тело коммита
Максимум **100 символов** в строке.

## Слияние PR
По умолчанию — **squash**.
Исключения: пара осмысленных коммитов или слияния `develop → master`.

## Проверка
`gitlint-action@v1.2.0` — CI падает при нарушении.
Если ветка не `develop` or `master`, правила применятся на открытом PR.
